## Course Introduction

This course introduces the core ideas behind database management systems and provides a practical path into MySQL.
You will learn how database systems are structured, why they are needed, and how to work with MySQL on Windows using both the command line and MySQL Workbench or VS Code.

## Course Syllabus

- Database basics and core terminology
- DBMS concepts, architecture, and use cases
- Relational thinking and database organization
- MySQL installation and connection setup
- Working with MySQL through command options, Workbench, and VS Code
