Chặng 1

Cài đặt MySQL Server trên Windows

Sử dụng MySQL Installer, cấu hình tài khoản root, port và Windows Service

1. Các bước cấu hình quan trọng trong MySQL Installer:

  • Choosing a Setup Type: Chọn Server only (chỉ database engine) hoặc Custom (để chọn cả MySQL Server + MySQL Workbench).
  • Type and Networking:
    • Config Type: Chọn Development Computer (tiết kiệm RAM nhất cho máy tính cá nhân).
    • TCP/IP Port: Mặc định là 3306. Nếu port này đã bị MariaDB hoặc XAMPP chiếm dụng, đổi sang 3307.
  • Authentication Method: Khuyến nghị chuẩn caching_sha2_password (mã hóa mật khẩu an toàn theo chuẩn SHA-256).
  • Root Password: Thiết lập mật khẩu cho tài khoản quản trị tối cao root.
  • Windows Service: Đặt tên service (mặc định MySQL80) và chọn tự động khởi chạy cùng Windows.

Cài đặt & Sử dụng MySQL Workbench GUI

Quản lý Connection profiles, SQL Query Editor và Schema Navigator

Các thành phần giao diện chính của MySQL Workbench:

  • MySQL Connections: Quản lý danh sách các profile kết nối. Mặc định có kết nối Local instance MySQL80 trỏ về 127.0.0.1:3306 với user root.
  • SQL Editor: Vùng soạn thảo câu truy vấn SQL với tính năng highlight cú pháp, gợi ý tự động (IntelliSense) và các nút thực thi:
    • Biểu tượng ⚡ (Tia chớp không con trỏ): Thực thi toàn bộ script trong editor.
    • Biểu tượng ⚡ kèm con trỏ: Chỉ thực thi câu lệnh SQL tại vị trí con trỏ chuột hiện tại (`Ctrl + Enter`).
  • Navigator (Schemas): Cây thư mục hiển thị tất cả cơ sở dữ liệu (Schemas), Tables, Views, Stored Procedures và Triggers.
  • Result Grid: Bảng hiển thị kết quả truy vấn, cho phép chỉnh sửa dữ liệu trực tiếp và xuất dữ liệu ra file CSV/JSON.

Kết nối MySQL qua Command Line Client

Làm chủ công cụ dòng lệnh `mysql` với các tham số `-h`, `-P`, `-u`, `-p`

1. Cú pháp kết nối dòng lệnh chuẩn:

mysql -h <host> -P <port> -u <user> -p
Tham sốÝ nghĩaVí dụ
-h / --hostĐịa chỉ IP hoặc hostname của server-h 127.0.0.1 hoặc -h db.example.com
-P / --portCổng dịch vụ MySQL (chú ý chữ P hoa)-P 3306
-u / --userTên tài khoản đăng nhập-u root
-p / --passwordYêu cầu nhập mật khẩu bảo mật-p (không gõ mật khẩu dính liền để tránh lộ)

2. Thao tác sau khi đăng nhập:

-- Hiển thị phiên bản server và user hiện hành
SELECT VERSION(), CURRENT_USER();

-- Xem danh sách database
SHOW DATABASES;

-- Chọn database làm việc
USE classicmodels;

-- Thoát khỏi CLI
EXIT;
🎯 Checkpoint Chặng 3
Câu 1: Trong câu lệnh `mysql -h 127.0.0.1 -P 3306 -u root -p`, vì sao tham số cổng mạng phải viết là `-P` chữ in hoa?
Câu 2: Để bảo mật thông tin trên terminal tránh bị người khác nhìn thấy mật khẩu hoặc lưu vào lịch sử lệnh (bash history), cách làm nào được khuyến nghị?

Tích hợp MySQL trong Visual Studio Code

Sử dụng tiện ích Database Client / SQLTools để lập trình CSDL trực tiếp

Lợi ích của việc quản trị MySQL ngay trong VS Code:

  • Môi trường lập trình nhất quán: Lập trình viên viết mã backend (Node.js, Python, Java) và câu truy vấn SQL trong cùng một IDE mà không phải chuyển qua lại giữa nhiều cửa sổ.
  • Các Extension phổ biến:
    • Database Client (của cweijan): Giao diện trực quan cực mạnh, hỗ trợ autocomplete, xem bảng, chỉnh sửa trực tiếp, export dữ liệu.
    • SQLTools kèm driver SQLTools MySQL/MariaDB.
  • Các thông số cấu hình Connection: 
    Connection Name: Local-MySQL80
Host:            127.0.0.1  (hoặc localhost)
Port:            3306
User:            root
Password:        (Mật khẩu đã tạo)
Database:        classicmodels (tùy chọn)

Chẩn đoán & Xử lý Lỗi Kết nối Phổ biến

Khắc phục Error 1045, Error 2003, xung đột cổng 3306 và tường lửa
Mã lỗi Mô tả triệu chứng Nguyên nhân cốt lõi Giải pháp khắc phục
Error 1045 (28000) Access denied for user 'root'@'localhost' (using password: YES) Sai mật khẩu hoặc gõ nhầm Caps Lock / bộ gõ tiếng Việt Unikey Kiểm tra phím Caps Lock, hoặc chạy quy trình khôi phục mật khẩu root qua tùy chọn --init-file.
Error 2003 (HY000) Can't connect to MySQL server on 'localhost' (10061) Tiến trình dịch vụ mysqld chưa được bật hoặc bị crash Mở services.msc trên Windows, kiểm tra service MySQL80 và bấm Start.
Port Conflict Port 3306 is already in use Cổng 3306 đang bị MariaDB (XAMPP/WAMP) hoặc một instance MySQL khác chiếm giữ Dùng lệnh netstat -ano | findstr 3306 để tìm Process ID (PID) hoặc đổi port của MySQL sang 3307 trong my.ini.
🎯 Checkpoint Chặng 5
Câu 1: Khi kết nối gặp thông báo `ERROR 2003 (HY000): Can't connect to MySQL server on 'localhost' (10061)`, hành động kiểm tra đầu tiên cần làm là gì?
Câu 2: Lỗi `ERROR 1045 (28000): Access denied for user 'root'@'localhost'` xuất hiện cho biết nguyên nhân gì?
