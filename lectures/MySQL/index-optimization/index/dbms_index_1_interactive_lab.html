Kiến thức trọng tâm — Phần 1 (Cơ bản)

Index giúp MySQL tìm kiếm dữ liệu nhanh hơn cho truy vấn lọc, nối bảng hoặc sắp xếp, đổi lại chi phí lưu trữ và bảo trì khi ghi (INSERT/UPDATE/DELETE). Toàn bộ thực hành chạy trực tiếp trên 8 bảng classicmodels.

Single-column & DDL cơ bản

Tạo/xóa secondary index bằng CREATE INDEX, ALTER TABLE hoặc DROP INDEX.

CREATE INDEX idx_customers_country ON customers(country);

Metadata & ANALYZE TABLE

Kiểm tra PK, FK index và Cardinality qua SHOW INDEX, SHOW CREATE TABLE, STATISTICS.

SHOW INDEX FROM orders;

Composite & Leftmost-Prefix

Đặt cột lọc bằng (=) trước cột lọc khoảng/sắp xếp; tránh trùng lặp thừa.

CREATE INDEX idx_orders_customer_date ON orders(customerNumber, orderDate);

EXPLAIN cơ bản

Quan sát possible_keys, key, rows, filtered và Extra (key=NULL khi scan rẻ hơn).

EXPLAIN SELECT * FROM orders WHERE customerNumber=103;
