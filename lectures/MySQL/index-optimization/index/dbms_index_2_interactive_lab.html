Kiến thức trọng tâm — Phần 2 (Nâng cao)

Tiếp nối Phần 1 (Cơ bản), phần Nâng cao tập trung vào kiến trúc lưu trữ InnoDB, các loại index đặc biệt và kiểm soát optimizer bằng Index Hints trên classicmodels.

Clustered Index (InnoDB)

1 Clustered Index (PK -> UNIQUE NOT NULL -> GEN_CLUST_INDEX); PK ngắn giữ secondary index gọn.

SHOW INDEX FROM customers;

UNIQUE & Prefix Index

UNIQUE bảo vệ business key; Prefix giảm dung lượng chuỗi dài (cảnh báo với UNIQUE prefix).

CREATE UNIQUE INDEX uq_customers_name ON customers(customerName);

INVISIBLE & DESC (8.0+)

INVISIBLE thử tắt index trước khi DROP; DESC key part phục vụ mixed ASC/DESC.

ALTER TABLE customers ALTER INDEX idx_customers_country INVISIBLE;

Functional Index & Rewrite

Ưu tiên viết lại range sargable trước khi dùng expression index ((expr)).

CREATE INDEX idx_orders_year ON orders ((YEAR(orderDate)));

USE / FORCE / IGNORE & Scope

Dùng đúng tên index; giới hạn scope FOR JOIN, FOR ORDER BY, FOR GROUP BY.

FROM orders FORCE INDEX(idx_orders_customer_date)

EXPLAIN ANALYZE & Modern Hints

Ưu tiên sửa nguyên nhân gốc và cân nhắc /*+ INDEX(...) */ theo đúng version MySQL.

SELECT /*+ INDEX(o idx_orders_customer_date) */ ...
