Kiến thức trọng tâm — Index 2

Tutorial 2 thực hành các loại index và chiến lược chọn index trực tiếp trên cơ sở dữ liệu mẫu classicmodels, chuyển các yêu cầu giải thích thành câu hỏi trắc nghiệm và các yêu cầu viết lệnh thành SQL tự chấm theo cấu trúc.

UNIQUE vs PRIMARY KEY

UNIQUE giữ business-key distinctness; nullable UNIQUE có thể nhận nhiều NULL.

CREATE UNIQUE INDEX uq_customers_name ON customers(customerName);

Prefix & selectivity

Đánh đổi kích thước index với distinct prefix; không dùng UNIQUE prefix cho full string.

CREATE INDEX idx_products_name_prefix ON products(productName(12));

Invisible & Descending

Invisible bị optimizer bỏ qua theo mặc định nhưng vẫn duy trì; descending key part giúp mixed-order.

ALTER TABLE customers ALTER INDEX idx_customers_country INVISIBLE;

Composite & clustered

Leftmost-prefix quyết định khả năng truy cập; secondary index records chứa primary key của InnoDB.

CREATE INDEX idx_orders_customer_date ON orders(customerNumber, orderDate);

Cardinality & functional

Cardinality trong SHOW INDEX là estimate; ưu tiên rewrite date range trước khi thêm expression index.

CREATE INDEX idx_orders_year ON orders ((YEAR(orderDate)));

Workload-driven

Chọn index từ query predicates, join, sort, selectivity, chi phí ghi và benchmark.

ANALYZE TABLE orders;
