Kiến thức trọng tâm về Window Functions

Window function (hàm cửa sổ) tính toán giá trị dựa trên một tập hợp các dòng liên quan tới dòng hiện tại mà vẫn bảo toàn đầy đủ các dòng chi tiết (không bị gom nhóm như GROUP BY). Mệnh đề PARTITION BY phân chia các phân vùng, ORDER BY quyết định thứ tự duyệt, và ROWS/RANGE xác định khung cửa sổ (frame).

SELECT sale_id, sales_rep, amount,
       SUM(amount) OVER (
         PARTITION BY sales_rep
         ORDER BY sale_date, sale_id
         ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
       ) AS running_total
FROM sales;
Lưu ý quan trọng: Mệnh đề WHERE được thực thi trước Window Functions nên không thể lọc trực tiếp kết quả của hàm cửa sổ trong cùng một khối SELECT. Cần bọc câu truy vấn trong CTE (WITH) hoặc Subquery để lọc.
