Kiến thức trọng tâm

Window function tính giá trị trên các dòng liên quan tới current row mà vẫn giữ các dòng chi tiết. PARTITION BY chia nhóm, ORDER BY quyết định thứ tự tính toán, và ROWS/RANGE quyết định phạm vi frame.

SELECT sale_id, sales_rep, amount,
       SUM(amount) OVER (
         PARTITION BY sales_rep
         ORDER BY sale_date, sale_id
         ROWS BETWEEN UNBOUNDED PRECEDING
                  AND CURRENT ROW
       ) AS running_total
FROM sales;

Lưu ý: WHERE không thể lọc trực tiếp giá trị window trong cùng SELECT; dùng CTE hoặc derived table. MySQL hỗ trợ window functions từ 8.0. Ở đây SQL được thực thi bằng SQLite WebAssembly, vốn hỗ trợ các hàm cửa sổ chính; một số cú pháp riêng MySQL khác biệt.
