Mô phỏng trực quan — Toán tử ALL & ANY

Giả sử truy vấn con trả về tập giá trị S = {10, 20, 30}. Kéo thanh trượt để thay đổi giá trị x và quan sát kết quả logic của ALL và ANY.

25
Lưu ý: Với tập rỗng, điều kiện > ALL(∅) trả về TRUE (vacuous truth), trong khi > ANY(∅) trả về FALSE.

-- Kiểm tra tồn tại
WHERE EXISTS (
  SELECT 1 FROM tbl2 WHERE tbl2.id = tbl1.id
)

-- So sánh tập hợp
WHERE col > ALL (SELECT val FROM ...)
WHERE col = ANY (SELECT val FROM ...)

Gợi ý làm bài

Với EXISTS, truy vấn con luôn là subquery tương quan có liên kết khóa với bảng ngoài.

Toán tử = ANY tương đương với IN. Toán tử <> ALL tương đương với NOT IN (lưu ý trường hợp NULL).
