Cú pháp tổng hợp

SELECT group_column, COUNT(*) AS n
FROM table_name
WHERE row_condition
GROUP BY group_column
HAVING COUNT(*) > 5
ORDER BY n DESC
LIMIT 10;
Phím tắt: Ctrl+Enter (Windows) hoặc ⌘+Enter (macOS) trong editor để chạy SQL. Có thể dùng DESC products; và SHOW TABLES;.
