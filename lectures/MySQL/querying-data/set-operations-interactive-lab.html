Kiến thức trọng tâm về Set Operations (Phép toán tập hợp)

Trong SQL, phép toán tập hợp (Set Operations) kết hợp các dòng dữ liệu từ hai hoặc nhiều câu lệnh SELECT (query block) thành một tập kết quả duy nhất (result set) theo chiều dọc.

1. UNION & UNION ALL

UNION: Hợp các result set và tự động loại bỏ các dòng trùng lặp (DISTINCT ngầm định).
UNION ALL: Gộp toàn bộ dòng và giữ nguyên các bản ghi trùng (nhanh hơn nhiều vì không cần sort/khử trùng).

2. EXCEPT (Hiệu hai tập hợp: A - B)

Trả về các dòng xuất hiện ở query block thứ nhất nhưng không xuất hiện ở query block thứ hai. Không có tính giao hoán: A EXCEPT B ≠ B EXCEPT A.

3. INTERSECT (Giao hai tập hợp: A ∩ B)

Trả về các dòng xuất hiện ở cả hai query block. Có tính giao hoán: A INTERSECT B = B INTERSECT A. Độ ưu tiên cao hơn UNION và EXCEPT.

4. Kỹ thuật thay thế trên MySQL cũ (< 8.0.31)

EXCEPT thay bằng: NOT EXISTS hoặc LEFT JOIN ... WHERE right_col IS NULL.
INTERSECT thay bằng: EXISTS hoặc INNER JOIN (kèm DISTINCT).

-- Cú pháp chung kết hợp hai tập hợp:
SELECT column_list FROM table_1
UNION | UNION ALL | EXCEPT | INTERSECT
SELECT column_list FROM table_2
ORDER BY column_name;
Quy tắc tương thích bắt buộc:
  • Các query block phải có cùng số lượng cột.
  • Các cột ở cùng vị trí thứ tự phải tương thích về kiểu dữ liệu và ý nghĩa (SQL so sánh theo vị trí 1-1, 2-2, không so sánh theo tên).
  • Tên cột của kết quả cuối cùng được lấy từ query block đầu tiên.
  • Mệnh đề ORDER BY và LIMIT đặt ở cuối áp dụng cho toàn bộ result set kết hợp. Nếu muốn áp dụng riêng cho từng khối, phải bọc từng khối trong dấu ngoặc đơn (...).

Ghi nhớ cú pháp Set Operations

-- UNION (loại trùng) / UNION ALL (giữ trùng)
SELECT country FROM customers
UNION ALL
SELECT country FROM offices;

-- EXCEPT (A - B)
SELECT country FROM customers
EXCEPT
SELECT country FROM offices;

-- INTERSECT (A ∩ B)
SELECT country FROM customers
INTERSECT
SELECT country FROM offices;

-- Thay thế EXCEPT trên MySQL < 8.0.31
SELECT DISTINCT c.country FROM customers c
WHERE NOT EXISTS (
  SELECT 1 FROM offices o WHERE o.country = c.country
);
Phím tắt: Nhấn Ctrl+Enter (hoặc Cmd+Enter trên macOS) trong khung soạn thảo để thực thi truy vấn ngay lập tức.
